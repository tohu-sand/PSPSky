# PSPSky

**Languages:** [日本語](README.md) | [English](README.en.md)

PSP(PlayStation Portable) 単体で動作する [Bluesky](https://bsky.app) クライアント homebrew です。

PSP から `bsky.social` へ **直接 TLS 1.2 接続**(libcurl + mbedTLS、CA 検証あり)してタイムラインの閲覧と投稿を行います。

---

## 特徴

- PSP 単体で完結 — PC やスマホを常時介在させる中継サーバー・プロキシは不要です。PSP から `bsky.social` へ直接 TLS 接続します(CA 検証あり)。
- ホームタイムラインの閲覧 — 表示名(無ければハンドル)・ハンドル・本文・相対時刻(「5分前」「3時間前」など)を表示します。cursor ページングで累計 100 件まで読み込めます。
- タイムラインの画像表示 — 画像付きの投稿には本文の下に 1 枚目のサムネイルを表示します(縦横比を保持)。2 枚以上ある投稿は `[画像 x3]` のように枚数を併記します。設定ファイルで無効にできます。
- テキスト投稿 — オンスクリーンキーボードで入力(日本語可、300 文字まで)。
- 画像添付 — JPEG / PNG を 1 投稿につき 1 枚(2,000,000 バイト以下)。投稿前にサムネイルのプレビュー画面が入り、ALT テキストも任意で付けられます。

---

## 対応機種と必要な環境

### 実機側

| 項目 | 内容 |
|---|---|
| 本体 | PSP-1000 / 2000 / 3000 |
| ファームウェア | [ARK-4](https://github.com/PSP-Archive/ARK-4) 等の CFW が導入済みであること |
| メモリースティック | 空き 2MB 以上 |
| Wi-Fi | XMB のネットワーク設定の 「接続設定1」 を使用 |
| アカウント | Bluesky アカウントと、発行済みのアプリパスワード |

PSP の無線 LAN は **802.11b のみ**です。本体の標準機能ではセキュリティは WPA-PSK (TKIP) までですが、[ARK-4](https://github.com/PSP-Archive/ARK-4) などの一部 CFW は WPA2 に対応しているため、導入済みなら WPA2 (AES) のアクセスポイントにそのまま接続できます。

### ビルド側(自分でビルドする場合のみ)

| 項目 | 内容 |
|---|---|
| SDK | [pspdev](https://github.com/pspdev/pspdev)(`psp-gcc`, `psp-config`) |
| PSP 側ライブラリ | libcurl / mbedTLS / zlib / intraFont(pspdev SDK に同梱) |
| ホスト側 | gcc (C99)、GNU make、openssl、curl(CA バンドル生成用) |

## インストール

事前に Bluesky のアプリパスワードを発行しておく(設定 → プライバシーとセキュリティ → アプリパスワード)。アカウント本体のパスワードは使わないようにしてください。

配置先は次のとおり。

```
ms0:/PSP/GAME/PSPSKY/
├── EBOOT.PBP      ← 本体
├── cacert.pem     ← assets/cacert.pem をコピー
└── pspsky.cfg     ← 初回ログイン後に自動生成される(先に手で置いてもよい)
```

`cacert.pem` が無い、あるいはパスが違うと TLS 証明書の検証に失敗してログインできません。

---

## 設定ファイル `pspsky.cfg`

`ms0:/PSP/GAME/PSPSKY/pspsky.cfg` に置くテキストファイル。

```
identifier=user.bsky.social
password=xxxx-xxxx-xxxx-xxxx
lang=en
images=on
```

| キー | 内容 |
|---|---|
| `identifier` | Bluesky のハンドル(`@` は付けない。カスタムドメインならそのドメイン) |
| `password` | アプリパスワード(`xxxx-xxxx-xxxx-xxxx` 形式、ハイフン込み) |
| `lang` | UI 言語の固定。`ja` または `en`。任意(省略時は自動判定) |
| `images` | タイムラインのサムネイル表示。`on`(既定)または `off`。任意。`off` にすると画像を取得せずマーカー表示だけになり、通信量と読み込み時間を節約できます |

- `=` の前後にスペースを入れないでください。引用符も不要です。行の順序は問いません。
- ファイルが無ければ起動時にオンスクリーンキーボードで入力を求められ、ログイン成功後に自動保存されます。入れ直したいときはファイルを削除してください。

### 平文保存に関する注意

**`pspsky.cfg` はハンドルとアプリパスワードを暗号化せずに平文で保存します。**
PSP には安全な鍵保管領域が無く、EBOOT からアクセスできる場所に鍵を置いても同じ実行ファイルを読める人には復号できてしまうため、見せかけの暗号化はしていません。

- **必ず Bluesky の「アプリパスワード」を使い、アカウント本体のパスワードは入力しないでください。**
  アプリパスワードは Bluesky の 設定 → プライバシーとセキュリティ → アプリパスワード
  から発行でき、いつでも個別に失効させられます。

## 操作方法

| ボタン | 動作 |
|---|---|
| ↑ / ↓(アナログスティック可) | スクロール |
| L | 先頭から再取得(更新) |
| R(または最下部でさらに ↓) | 過去方向へ続きを読み込む(累計 100 件まで) |
| △ | 投稿を作成(オンスクリーンキーボード、300 文字まで) |
| ○ | 決定 / 確認(画像プレビュー画面ではこの画像で投稿) |
| □ | 投稿確認画面: 画像(JPEG / PNG)を 1 枚添付して投稿 |
| × | キャンセル(画像プレビュー画面では選び直し) |
| START | 終了 |

### オンスクリーンキーボードでの日本語入力

| ボタン | 動作 |
|---|---|
| SELECT | 文字種の切り替え(ひらがな / カタカナ / 英数 / 記号) |
| △ | 変換(ひらがな入力中)/ 空白(未入力時) |
| ↑ / ↓ | 変換候補の選択 |
| ○ | 確定 |
| START | 入力を終えて確認画面へ |

ひらがなを入力した状態で △ を押すと変換候補が出ます。候補を ↑ / ↓ で選び、○ で確定します。

### タイムラインの画像表示

画像を含む投稿は、本文の下に 1 枚目のサムネイルを表示します(縦横比は保たれます)。2 枚以上ある投稿では、サムネイルの下に `[画像 x3]`(英語 UI では `[images x3]`)と枚数が入ります。

サムネイルを表示できなかった場合は、代わりに `[画像]`(英語 UI では `[image]`)のマーカーだけを表示します。引用投稿やリンクカードなど画像を持たない embed も、従来どおりマーカーのみです。

取得中は「画像を取得中 (n/m)...」と進捗が出ます。1 枚あたり 0.2〜0.5 秒程度が目安です。

### 画像を添付して投稿する

本文を入力して確認画面まで進み、○ の代わりに □ を押すとファイルブラウザが開きます。

ファイルを確定するとプレビュー確認画面が入り、サムネイル・ファイルパス・ファイルサイズ・元画像の寸法が表示されます。プレビューの後に ALT テキスト(画像の説明)を入力できます(任意)。

- PSP の 802.11b では 2MB 近い転送に時間がかかります。「画像をアップロード中...」の
  表示中は最大 180 秒ブロックするので、画面が止まって見えても電源を切らずに待機してください。

## ビルド方法

pspdev SDK を導入したうえで、環境変数を通してください。

```sh
export PSPDEV=/path/to/pspdev
export PATH=$PSPDEV/bin:$PATH
psp-gcc --version   # 動作確認
```

リポジトリのルートで `make` を実行すると `EBOOT.PBP` が生成されます。

```sh
make            # → EBOOT.PBP
```

生成された `EBOOT.PBP` と `assets/cacert.pem` をメモリースティックにコピー・配置してください。

### CA バンドル (`assets/cacert.pem`)

PSP からはルート証明書を取得する手段が無いため、必要な 6 枚のルート証明書だけをバンドルしてリポジトリに含めています(完全な CA バンドルは約 180KB / 140 証明書あり、PSP のメモリと読み込み時間に対して過大)。

| 証明書 | 用途 |
|---|---|
| Amazon Root CA 1〜4 | `bsky.social` の現行チェーン(Amazon Trust Services) |
| Starfield Services Root Certificate Authority - G2 | Amazon Root CA 1 のクロス署名元 |
| ISRG Root X1 | Let's Encrypt(将来の切り替え・CDN 差異への備え) |

更新が必要になったら再生成してください。

```sh
sh tools/make_cacert.sh    # → assets/cacert.pem を再生成
```

スクリプトは `https://curl.se/ca/cacert.pem` から取得します。ネットワークが使えない場合は、ホストの `/etc/ssl/certs/ca-certificates.crt` から同じ 6 枚を openssl で抽出する代替経路に自動的に切り替わります。

### リポジトリ構成

```
.
├── Makefile                 PSP 向けビルド(EBOOT.PBP)
├── tools/make_cacert.sh     CA バンドル生成スクリプト
├── assets/cacert.pem        CA バンドル
├── vendor/cjson/            cJSON v1.7.18(ベンダリング)
├── vendor/picojpeg/         picojpeg(ベンダリング)
├── vendor/libwebp/          libwebp(ベンダリング、デコーダのみ)
├── include/pspsky/          共有ヘッダ
├── src/core/                ポータブルコア(C99、PSP 非依存)
└── src/psp/                 PSP シェル(ネットワーク・OSK・UI・エントリポイント)
```

`src/core/` は `#include <psp...>` を含まない C99 コードで、PSP 依存部との境界は `pspsky_transport_t`(`include/pspsky/transport.h` の関数ポインタ vtable)ひとつです。

## トラブルシューティング

TLS 関連のエラー画面には `(curl:数字)` の形式でエラーコードが表示されます。

| 症状 | 確認すること |
|---|---|
| 「cacert.pem を読み込めません」(curl:77) | 表示されたパスに `cacert.pem` があるか。Windows の拡張子非表示で `cacert.pem.txt` になっていないか。フォルダ階層が `PSP/GAME/PSPSKY/` になっているか(二重フォルダに注意) |
| 「サーバー証明書の検証に失敗しました」(curl:60) | 本体の日時設定(年・タイムゾーン含む)。それでも出る場合は `tools/make_cacert.sh` で `cacert.pem` を再生成して差し替える |
| 「TLSハンドシェイクに失敗しました」(curl:35) | 電波状態の悪化や接続の瞬断。ルーターに近づいて L で再試行 |
| アクセスポイントに接続できない | **WLAN の物理スイッチ**(PSP-1000 は左側面、2000/3000 は上面左)→ ネットワーク設定の**「接続設定1」**→ ルーターが 2.4GHz 帯 (802.11b) を有効にしているか。WPA2 (AES) は ARK-4 の対応機能で接続可、WPA3 専用は不可 |
| ログインに失敗する | ハンドルのつづり(`@` 不要)。**アプリパスワード**をハイフン込みで入力したか。不安なら発行し直す |
| 「しばらく待ってから再試行してください」 | Bluesky 側のレートリミット。数分待ってから L で更新する |
| 起動直後に XMB に戻る | `EBOOT.PBP` のコピーが壊れている可能性。コピーし直す。CFW が有効かも確認 |
| 日本語が表示されない・文字化けする | 本体フォント `flash0:/font/jpn0.pgf` を読めていない可能性(海外版本体など) |
| 画像が表示されず `[画像]` のままになる | 取得に失敗した(電波状況・アクセスポイント切断)/ 未対応の画像形式だった / 画像キャッシュの上限(約 4MB)に達した / `pspsky.cfg` で `images=off` にしている、のいずれか。L で更新すると取り直します |
| タイムラインの読み込みが遅い | 画像の取得に 1 枚あたり 0.2〜0.5 秒かかります。`pspsky.cfg` に `images=off` を書くと画像を取得しなくなり、読み込みが速くなります(行を消せば元に戻ります) |
